# Anomia XLSX — descargas

Pseudonimizador local de planillas Excel (RUT y número de ficha a códigos, con tabla de mapeo
reversible). Hecho por Maxand · Dr. Maximiliano Rodríguez Pavez, CESFAM Huequén.

Este repositorio contiene **solo las versiones publicadas** de Anomia XLSX, en la pestaña
[Releases](https://github.com/maxandrp/AnomiaXLSX-releases/releases). El código fuente es privado.

## Descargar

En la Release más reciente, bajar **AnomiaXLSX.exe**. No requiere instalación.

## Actualizaciones

Anomia XLSX busca aquí una versión nueva cada vez que se abre. Si la hay, avisa y ofrece
instalarla. No envía ningún dato: solo lee la lista pública de versiones.
